# 舰艇模拟战

基于 Vite、React、TypeScript 和 Babylon.js 的俯视角海战模拟游戏。玩家可以观察红蓝两支舰队自动交战，也可以选择舰船下达航行和攻击指令。

## 当前功能

- 红蓝双方各有两艘舰船；舰船巡航寻找敌舰，并自动使用主炮和鱼雷交战。
- 鱼雷会触发舰船规避机动；舰船受损时会冒烟，生命值越低，烟雾出现越频繁。
- 舰船互相碰撞时会被推开；命中、爆炸、炮弹落海和烟雾均有粒子效果。
- 舰船有生命条、选中圈、炮塔转向、命中闪光和规避状态显示。
- 一方被全歼后仍会结算飞行中的弹药，并等待 3 秒再判定胜负；若等待期间双方全灭则判为平局。
- 游戏结束后点击画面重新开始。
- 支持中英文界面。默认海域为浅海；海洋测试页可预览和切换海域类型。
- 大地图采用 1600 x 900 的相机视口跟随交战区域，右下角小地图显示整张海图、双方限制区、舰船位置和当前视口；点击小地图可跳转视口。

## 地图尺寸与性能平衡

- 世界尺寸集中在 `src/game/world.ts`：当前 `5120 x 2880`，相对原 `1600 x 900` 面积约 **10.24 倍**（线性约 3.2 倍）。
- 性能平衡区间（当前架构：正交相机 + 单张程序化海面 + 屏幕像素成本固定的着色器）：
  - **线性 2~4 倍（面积 4~16 倍）**：安全区间。视口像素和海面细分数固定，世界变大只增加少量顶点和坐标范围。
  - **线性 4~8 倍（面积 16~64 倍）**：需要视口裁剪（只渲染可见海面分块）、海面 LOD 和空间划分。
  - **线性 8 倍以上**：浮点精度、索敌遍历和弹道飞行时长成为瓶颈，需要分块加载或 floating origin。
- 当前 3.2 倍位于安全区间；海面细分数按视口像素密度设为 320 x 180，不随地图面积线性增长。

## 行动限制区

- 行动限制区由 `src/game/RestrictArea.ts` 的 `RestrictArea` 类统一管理：先按地图定义限制区（红方左半区、蓝方右半区），再摆放船，先限制区后有船。
- 限制区按阵营划分，以海面虚线框划出，颜色跟随阵营（红方 `#ff7b6b`、蓝方 `#7cc4ff`），带 35% 透明度，Z 层贴在海面之上。
- **所有船都必须在阵营限制区内**，包括手动摆放的船。画船前会验证船位置是否在范围内，超出则直接拒绝渲染并弹 modal 提示，避免摆到外面破坏公平性。
- **自动摆船**：主游戏通过 `RestrictArea.createShip(cfg)` 自动在阵营限制区内分配船的 `x`/`y`，并按阵营分配朝向 `dir`（红方朝右、蓝方朝左）。大地图上出生点收拢到中线附近的集结带（X 650、Y 720），避免开局双方隔屏相望；`TestShip` 调试页仍保持手动指定 `x/y/dir`。
- 限制区支持战斗运行中取消：调用 `RestrictArea.cancel()` 可一次性销毁虚线框并取消限制（界面上暂无直接开关）；单艘取消可调用对应 `RestrictArea` 实例的 `cancel()`。取消后船可在全图自由行动。

## 操作

- 左键选择舰船；按住 Shift 并左键可多选。
- 右键点击海面，让选中的舰船驶向目标位置。
- 将鼠标移到目标位置后按 F，命令选中舰船向该位置齐射；手动攻击有 2.5 秒公共冷却。
- 在小地图按下并拖动可连续移动相机视口，松开或移出小地图即停止；选中舰船后相机会优先跟随选中舰队。
- WASD 或方向键按住可平移相机视口，边界会自动限制在地图范围内。
- 游戏结束后点击画面重新开始。

## 页面

- `/`：主战场。
- `/hud`：HUD 预览与测试。
- `/expanse`：海域外观测试及海域类型切换。
- `/weapons`：武器参数与弹道测试。
- `/ship`：舰船行为和外观测试。

## 技术栈

- React 19、TypeScript、Vite 8。
- Babylon.js：正交俯视场景、舰船与粒子渲染；部分绘图资源使用 `DynamicTexture`。
- React Router：页面路由。
- i18next、react-i18next：中英文界面，默认中文。
- pnpm：包管理。

## 安装与运行

```bash
pnpm install
pnpm dev       # 本地开发服务器，默认 http://localhost:5173
pnpm build     # 生产构建
pnpm preview   # 预览生产构建
pnpm lint      # 格式检查和 Oxlint
```

## 主要代码入口

- `src/game/Game.ts`：对局初始化、更新循环、碰撞、粒子和结束判定。
- `src/game/world.ts`：世界尺寸、视口尺寸和性能平衡区间说明。
- `src/game/camera-focus.ts`：大地图相机跟随、minimap 跳转和屏幕/世界坐标换算。
- `src/game/utils.ts`：舰船移动、转向、规避等参数 `P`。
- `src/weapons/spec.ts`：主炮和鱼雷的伤害、射程、速度、冷却等武器参数。
- `src/ship/index.ts`：舰船 AI、伤害和受损烟雾。
- `src/game/render.ts`、`src/ship/render-visual.ts`：Babylon.js 场景同步和舰船视觉资源。
- `src/expanse/`：海域状态、海面渲染和海洋着色器。
- `src/playground/`：HUD、海域、武器和舰船测试页面。

## 目录结构

```
src/
  App.tsx           路由与页面导航
  components/       共用 UI（Hud、Minimap、Model、BattleCanvas 等）
  game/             对局逻辑（Game、碰撞、粒子、渲染、选中）
  ship/             舰船 AI、伤害、视觉资源
  weapons/          武器参数与弹道
  expanse/          海域状态与海面渲染
  playground/       各功能测试页面
  locales/          i18n 语言包
```

项目目前没有单独配置自动化测试脚本；可用 `pnpm build` 和 `pnpm lint` 检查构建与代码规范。
