# 舰船移动行为说明

本文说明 `src/ship/` 下舰船“怎么走”：决策优先级、行动模式、规避状态机，以及统一运动层 `locomotion.ts` 的转向 / 加减速 / 地形 / 边界 / 卡位处理。武器发射不在本文范围内。

## 1. 总览

移动分成两层：

- **决策层**：只输出意图 `{ heading, speedFactor }`，不直接改坐标。
  - `ActionMode`：行动模式（小型舰环绕炮战、无目标巡航）。
  - `EvasionBehavior`：鱼雷规避。
  - 玩家手动航行指令。
- **执行层**：`driveShip()` 统一负责转向、平滑加减速、地形预避让、限制区边界、转向疲劳、卡位脱困，并写回 `x / y / vx / vy / dir`。

控制优先级（从高到低）：

```
玩家手动航行指令 > 鱼雷规避 > ActionMode（无目标时退化为默认巡航）
```

> `ShipImpl.update()` 每帧顺序：计时器 / 特效 → 鱼雷齐射队列 → 多炮塔齐射队列 → 按上述优先级决定移动 → 更新武器。
> 武器逻辑不会反过来影响本帧的移动。主炮每门炮塔各自发射一发炮弹，按 `GUN_SALVO_INTERVAL` 逐门打出。

## 2. 手动航行（最高优先级）

入口是 `src/game/movement.ts`。

**下达指令 `issueSailOrder()`**

- 目标点会先夹到可航行范围：`x ∈ [minX, maxX]`（本舰限制区），`y ∈ [P.yMin, P.yMax]`（地图上下边界）。
- 立刻清空所有“AI 状态”，让玩家指令马上生效：
  - 脱离规避 / 回正状态（`state = "normal"`）。
  - 清目标 `target = null`、转向疲劳 `turnFatigue = 0`、卡位计时 `stuckT = 0`。
  - 重置行动模式内部状态（`actionMode.reset()`）。
  - 清空运动层内部状态（`resetDriveMemory()`，包括贴边平行与减速标记）。

**每帧推进 `updateSailOrder()`**

- 距目标 ≤ `ARRIVE_RADIUS`（6px）：直接吸附到目标点、停船、清除指令，下一帧恢复行动模式。
- 否则用 `driveShip()` 朝目标点走：
  - `bounce: false`：不做 AI 的边界预折返 / 反弹 / 贴边平行，只在最后 clamp 到边界。
  - `alignSpeed: true`：航向偏差大时按 `max(0, cos(偏差))` 降速，先转体再前进，保留旧手感。
  - 地形预避让仍然生效。

## 3. 鱼雷规避状态机

状态存放在 `ship.state`：`normal` / `dodge` / `recover`（HUD 文案仍是 normal / dodge / recover）。规避逻辑实现在 `src/ship/evasion.ts`，可替换实现。

**触发**

- 只在 `normal` 状态下检测。
- `findThreat()` 只把**鱼雷**当威胁：未来 2.2 秒内、最近接近距离小于鱼雷危险半径、相对速度足够大。取最早命中的一发。
- 有威胁时调用 `startEvasion()`：委托 `EvasionBehavior.decide()` 给出方案，然后切到 `dodge`。
- 注意：触发规避的这一帧**不移动**（走的是 `startEvasion` 分支，不调用 `driveShip`），下一帧才执行规避机动。

**默认规避行为 `DefaultEvasionBehavior`**

- 横向候选只有向上 / 向下两个位置：`ship.y ± amplitude`（默认 42px）。
- 对全部存活敌方鱼雷做预测，计算每个候选点对所有鱼雷的**最坏情况余量**（最近接近距离 − 危险半径 − 半船宽），选更安全的一侧。
- 没有鱼雷数据时退化为“远离预测命中点”。
- 输出方案：`speedFactor = 0.65`、`duration = 0.85s`、`amplitude = 42px`。

**`dodge` 阶段（直接改坐标，不走 `driveShip`）**

- 舰体以固定转向速率转向垂直于基准航向的方向（`baseAngle ± 90°`）。
- Y 向往 `baseY ± amplitude` 移动，并夹在 `P.yMin / P.yMax` 内。
- 沿 `dir` 以 `moveSpeed × 0.65` 前进；左右越界时反弹并更新 `dir`。
- 持续时间到且已无威胁 → 进入 `recover`；仍有威胁则继续规避。

**`recover` 阶段**

- 以固定转向速率转回 `baseAngle`，同时把 `y` 拉回 `baseY`。
- 每帧重新检测威胁，一旦又有鱼雷来袭立刻重新规避。
- 航向误差 < 0.02 rad、位置误差 < 0.5px、且本次规避已持续超过 0.35s → 回到 `normal` 并吸附到位。

> 规避 / 回正仍沿用旧的“沿 X 轴前进 + Y 横移”模型，不经过统一运动层。
> 代码中有 `TODO(鱼雷规避)`：未来改为候选机动评分（加速 / 减速 / 左右横移组合）。

## 4. 行动模式（ActionMode）

### 4.1 抽象

- `ActionMode.update()` 只返回意图，不修改位置。
- 行动模式自己维护 `target`（供开火逻辑复用）。
- 玩家下达手动航行指令时调用 `reset()`，清空目标与阶段状态。
- 舰种通过 `shipClass` 选择模式；目前鱼雷艇和护卫舰共用 `SmallShipAction`。

### 4.2 小型舰 `SmallShipAction`

**索敌**

- 当前目标活着就一直锁定，不重新选目标；目标死亡后才用 `findTarget()` 取最近的存活敌舰。

**阶段**

| 阶段       | 进入条件                         | 航向                            | 速度倍率                    |
| ---------- | -------------------------------- | ------------------------------- | --------------------------- |
| `search`   | 没有目标                         | 东 / 西（由 `dir` 决定）        | 1.0                         |
| `approach` | 距离 > 主炮射程 × 0.9            | 目标方位 ± 0.35 rad（斜向接近） | 距离 > 2R 时 1.6，否则 1.35 |
| `engage`   | 距离 ≤ 主炮射程 × 0.9            | 切线 ± 径向修正                 | 0.7 ~ 1.15                  |
| `loop`     | 距离 < 0.55R 或目标在船尾 > 115° | 同 `engage` 的切线航向          | 1.6                         |

- 环绕半径 `R = max(280, 舰长 × 4)`，小舰（长 100）为 400px。
- 切线航向：`目标方位 + side × (90° − 径向误差 × 55°)`，`径向误差 = clamp((距离 − R) / R, -1, 1)`：
  - 太远 → 航向向目标内侧偏，边绕边接近；
  - 太近 → 航向向目标外侧偏，拉开距离。
- `engage` 速度：偏远时 `min(1.15, 0.8 + 误差/R × 0.35)`；偏近时 `max(0.7, 0.8 + 误差/R × 0.1)`。
- `loop` 至少持续 0.8s，且距离恢复到 `0.7R` 以上才回到 `engage`。
- 进入 `engage` 时选环绕方向：比较左右两侧的转向代价，并对“航向会越界”加 180° 代价、对“前方被地形挡住”加 126° 代价，选代价小的一侧。
- 目标更换时重置为 `search`。

> 行动模式**不再自己处理限制区边界**。靠近边界时的折返 / 贴边平行 / 减速全部由下面的运动层统一处理。

## 5. 统一运动层 `driveShip()`

接口：

```ts
driveShip(ship, heading, speedFactor, dt, {
  bounce, // AI：边界预判、反弹、贴边平行；手动指令为 false
  alignSpeed, // 手动指令：航向偏差大时减速
  avoidTerrain, // 默认 true
  useTurnFatigue, // AI 用转向疲劳；手动指令为 false
});
```

每帧处理顺序：

1. 卡位检测（用上一时间窗的净位移判断）。
2. 地形预避让。
3. 限制区边界处理（仅 AI）。
4. 卡位脱困覆盖（仅 AI）。
5. 目标速度与平滑加减速。
6. 按转向疲劳决定是否转向，并累计 / 恢复疲劳。
7. 位移、边界 clamp / 反弹、由实际位移反推 `vx / vy`，再更新 `dir`。

### 5.1 速度

- 目标速度倍率 = `clamp(意图, speedMin, speedMax)`，默认 `0.7 ~ 1.6`。
- 脱困时压到 `0.7`（再夹进 `speedMin ~ speedMax`）；“边界大转向”时压到 `speedMin`。
- 用 `approachValue(current, target, accelRate × dt)` 平滑逼近，默认 `accelRate = 1.2`，不会瞬间变速。
- 实际速度 = `P.moveSpeed × cruiseFactor × speedFactor`：
  - `P.moveSpeed = 120`，`cruiseFactor` 默认 `P.normalFactor = 0.5`；
  - 因此倍率 0.7 / 1.0 / 1.6 对应约 42 / 60 / 96 px/s。
- 行动模式不算 `alignSpeed`：船始终沿**当前船头**方向前进，转向过程中不会“横着飘”。
- 手动指令算 `alignSpeed`：航向偏差越大越慢。

### 5.2 地形预避让

- 碰撞半径 = `半船宽 + 12px`。
- `avoidAngle()` 从期望航向开始尝试 `0° / ±25° / ±50° / ±75° / ±100°`，返回第一个前方通畅的方向；通畅判定在 45% / 75% / 100% 前视距离处采样。
- 地形导致航向改变时视为“必须转”，不受转向疲劳限制。

### 5.3 限制区 / 地图边界

只对 AI（`bounce: true`）做提前处理；手动指令只做最终 clamp。

**前视检查**：沿期望航向前视 240px，越界才处理。边界分两种：

- 左右边界（`minX / maxX`）：竖线，平行航向是 ±90°。
- 上下边界（`P.yMin / P.yMax`）：横线，平行航向是 0° / 180°。

**处理顺序**

1. **先试浅转贴边**：找出“转向严格小于 30°”就能顺着边界走的平行航向。
   - 候选只来自当前越界方向对应的两条平行航向。
   - 候选本身若马上又会撞到相邻边界（角落），直接排除。
   - 多个候选取转向最小的一条。
2. **能浅转**：转入平行并保持至少 2.5 秒，速度不降。
   - 保持期内若平行航向会撞到相邻边界，立刻结束保持并重新判断。
   - 记录跟随的是哪条边界，每帧计算船心到该边界的垂直距离 `d`：
     - `d ≤ 120px`（`BOUNDARY_PARALLEL_NEAR`，“真的贴边了”）：保持纯平行，并**持续额外恢复转向疲劳 0.4/s**（叠加直线恢复 0.45/s）。
     - `d > 120px`：说明离边界还远、只是前视提前触发。此时不再死板平行，而是按“索敌权重”把航向逐渐拉回行动模式的原始意图，让船主动朝目标方向压，直到真正逼近边界再转为平行，避免一条直线巡边到底。
       权重 = `clamp((d − 120) / (240 − 120), 0, 1)`：
       - `d = 120px` → 权重 0（纯平行）；
       - `d ≥ 240px` → 权重 1（完全回到索敌意图）。
   - 120px 这个阈值同时控制“是否算贴边（疲劳恢复）”和“索敌权重起点”，调整时请一起评估，代码中有详细注释。
3. **30° 内没有平行解**：说明需要大角度转向。
   - 先把航向按边界镜像折回场内。
   - **锁存减速**：目标速度压到 `speedMin`，一直减到最低速才解除（避免掉一点头又恢复巡航）。
   - 减速期间除原有的 `0.9/s` 减速恢复外，再额外恢复转向疲劳 `0.5/s`。
4. **兜底**：无论提前处理如何，最终都会把 `x` 夹到 `[minX, maxX]`、`y` 夹到 `[P.yMin, P.yMax]`；AI 的 `bounce` 模式在撞线时还会镜像反弹航向（左右 `π − θ`、上下 `−θ`）。

### 5.4 转向疲劳（转动意愿）

- 范围 0 ~ 1。实际转过 180° 累计到 1（每帧 `+ 实际转角 / π`）。
- **死区**：疲劳为 `F` 时，若当前不是“必须转”，会忽略小于 `F × 30°` 的航向修正。满疲劳时最多忽略 30° 的小修正，避免每帧追着径向误差来回摆；大角度转向仍会执行。
- **必须转**（无视死区）：地形避让、边界处理、卡位脱困。
- 恢复速度：
  - 直线航行（这一帧几乎没转）：`0.45/s`；
  - 正在减速：额外 `0.9/s`；
  - 边界大转向减速：再额外 `0.5/s`；
  - 真正贴边平行（距离 ≤ 120px）：额外 `0.4/s`。
- 玩家手动指令会把疲劳清零。

### 5.5 卡位检测与脱困

- 每 1.5s 比较一次净位移；只关心“想走”（`speedFactor > 0.2`）的船。
- 净位移小于 `max(24px, 期望位移 × 0.2)` 时累计卡位时间，否则以 2 倍速度衰减。
- 卡位时间 ≥ 1.5s 视为卡住：
  - 向 16 个方向试探，评分优先保持当前航向、前方通畅加分、越界大幅减分；
  - 选最优方向脱困，速度压到 `0.7`（再夹进 `speedMin ~ speedMax`），全程强制转向（忽略疲劳）；
  - 脱困期间跳过边界贴边逻辑，但仍受最终边界 clamp。
- 卡住会 `console.error` 输出位置与疲劳，节流 2s 一次，便于定位地形 / 边界问题（属于有意的调试输出）。

### 5.6 位移与速度同步

- 按当前船头方向前进，写入位置后统一 clamp。
- `vx / vy` 由**实际位移 / dt** 反推，保证预判瞄准、鱼雷威胁计算读到的是真实速度。
- `|vx| > 1` 时更新 `dir`（用于 `search` 航向与旧规避逻辑）。
